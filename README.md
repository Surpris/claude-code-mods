# claude-code-mods

Claude Code 用の Mod を集めたマーケットプレイスです。

## インストール

```
/plugin marketplace add Surpris/claude-code-mods
/plugin install <mod名>@claude-code-mods
```

## 収録している Mod

| Mod | 説明 |
|---|---|
| `wsl-path-links` | WSL 上で、Claude の返答に含まれるローカルパスをクリックできるようにする。ファイルはビューアーペインに、ディレクトリは Windows エクスプローラーに開く。全画面ターミナル（`"tui": "fullscreen"`）が必要。 |
